IndexedDB DevTools Panel

Browse, search, edit and export IndexedDB data in a DevTools panel.

A Chrome extension that adds one panel to DevTools, turning IndexedDB into a readable, searchable table — with in-place editing and JSON export. It makes no network request and requests a single permission.

Privacy policy → The one document Chrome Web Store reviewers need. Source code → Every claim verifiable. No build step, no frameworks.

What it does

  • Table view with columns inferred from your records; primary key highlighted.
  • Global search across every field name and value in the store.
  • Full cell inspection, and in-place editing written back via objectStore.put().
  • Export the current store or the whole database to JSON.
  • Chinese and English UI, following the browser language, switchable in the toolbar.

This site is static and self-contained: no fonts, scripts, images, or CDN. It is served from the project's own repository.
