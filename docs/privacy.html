Privacy Policy — IndexedDB DevTools Panel

Effective: 21 November 2026 · Last updated: 23 November 2026 · Version: 1.1.0

This extension does not collect, transmit, or share any user data. It makes no network requests at all, and it requests exactly one permission.

English

What the extension handles

The extension adds a panel to Chrome DevTools. When you open that panel yourself, it reads the IndexedDB databases and object stores of the page currently open in the inspected tab, and renders them as a table in that panel. Nothing else is read.

Everything happens locally, inside your browser. Browsing, searching, editing a record, writing it back, and exporting to JSON are all local operations. When you export, the browser saves the file to a location you choose; the extension keeps no copy.

What the extension does not do

  • No network access. There is no fetch, XMLHttpRequest, WebSocket, beacon, analytics, or crash reporting anywhere in the code. No network-capable permission is requested.
  • No browsing history, no tab access, no injection into arbitrary pages. There are no content scripts and no host permissions.
  • No stored settings, no telemetry, no accounts, no backend. The extension does not use chrome.storage or any other persistence beyond a single language preference kept in the DevTools page's own localStorage.
  • No selling or sharing of data. There is no data to sell or share.
  • No remote code. All code ships inside the package; nothing is fetched or evaluated at runtime.

The one permission: clipboardWrite

It is used for exactly one thing — the Copy buttons. When you click Copy on a row, in the cell-detail dialog, or in the edit dialog, the record's JSON is written to your system clipboard so you can paste it elsewhere.

The extension never reads the clipboard: clipboardRead is not requested and there is no paste feature. The write happens only in direct response to your click — never on load, in the background, or on a timer.

Children

The extension is a developer tool and is not directed at children. It collects no personal information from anyone, of any age.

Changes to this policy

If the extension's data handling ever changes, this page will be updated and the "Last updated" date above will change before the new version is published. The full revision history is public in the source repository.

Verifying these claims

The source is public, so every statement above can be checked directly. The extension is a handful of readable files — manifest.json, devtools.html, devtools.js, panel.html, panel.js, i18n.js — plus two UI string dictionaries. Grep the repository for fetch, XMLHttpRequest, WebSocket, or chrome.storage: there are no matches. manifest.json contains "permissions": ["clipboardWrite"] and nothing else.

中文

扩展处理哪些数据

本扩展在 Chrome DevTools 中新增一个面板。当你主动打开该面板后，它读取 当前被检查标签页里那个页面的 IndexedDB 数据库与 object store， 以表格形式渲染在这个面板里。除此之外不读取任何东西。

所有操作都在你本机的浏览器内完成：浏览、搜索、编辑某条记录、写回、导出为 JSON， 全部是本地行为。导出时由浏览器把文件保存到你选择的位置，扩展不保留副本。

扩展不做什么

  • 不联网。代码里没有任何 fetch、 XMLHttpRequest、WebSocket、beacon、埋点或崩溃上报， 也没有申请任何能访问网络的权限。
  • 不读浏览记录、不访问标签页、不向任意页面注入。 没有内容脚本，没有主机权限。
  • 不存储配置、不上报统计、没有账号体系、没有服务器。 扩展不使用 chrome.storage，也不做其他持久化；唯一的例外是 DevTools 页面自身 localStorage 里记的一项语言偏好。
  • 不出售、不共享数据。本来就没有数据可供出售或共享。
  • 不使用远程代码。全部代码随安装包一起分发，运行时不下载、 不执行任何远程内容。

唯一申请的权限：clipboardWrite

它只用于一件事——复制按钮。当你在行内、单元格详情弹窗或编辑弹窗中点击「复制」时， 该条记录的 JSON 会被写入系统剪贴板，方便你粘贴到别处。

扩展从不读取剪贴板：没有申请 clipboardRead，也没有粘贴功能。 写入只由你的点击直接触发，不会在页面加载时、后台或定时器里发生。

关于儿童

本扩展是开发者工具，并非面向儿童。它不收集任何人的个人信息，无论年龄。

政策变更

如果扩展的数据处理方式将来发生变化，本页面会在新版本发布之前更新，并修改上方的 「最后更新」日期。完整修订历史在源码仓库中公开可查。

如何核对这些声明

源码是公开的，上面每一条都可以直接验证。整个扩展只有几个可读的源文件—— manifest.json、devtools.html、devtools.js、 panel.html、panel.js、i18n.js——外加两份界面 文案字典。在仓库里搜索 fetch、XMLHttpRequest、 WebSocket 或 chrome.storage，不会有任何命中。 manifest.json 里只有 "permissions": ["clipboardWrite"]， 没有别的。
